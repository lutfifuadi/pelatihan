
Check Number API
Api Docs Checking Number
Method : POST | GET

Endpoint: https://wa.lutfifuadi.my.id/check-number

Request Body : (JSON If POST)

Parameter	Type	Required	Description
api_key	string	Yes	API Key
sender	string	Yes	your number ex 62888xxxx
number	string	Yes	any number ex 62888xxxx

Example JSON Request

{
    "api_key": "EyVsT4Ad3WHvTn6vadbfv9MabCLowX",
    "sender": "6288989470609",
    "number": "201111xxxxxx"
}
Example URL Request

https://wa.lutfifuadi.my.id/check-number?api_key=1234567890&sender=6281222xxxxx&number=201111xxxxx
Example JSON Response

{
	"status": true,
	"msg": {
		"exists": true,
		"jid": "201111xxxxxx@s.whatsapp.net"
	}
}
